# Capstone Project II — Topic To Be Confirmed

**Status: in progress — topic selection underway.**

The second end-to-end capstone project of the current term.

## Scope

Domain, dataset, and method are open by design. The project will follow the full data science
process rather than stopping at exploratory analysis, and will include modeling. The deliverable is
a useful analysis for people working in the chosen domain, told as a jargon-free story.

## Planned structure

| Stage | Output |
|---|---|
| Proposal and data selection | Research questions, data source, ethical implications |
| Draft white paper | 3–5 pages with at least 3–5 supporting illustrations and an appendix |
| Presentation | Recorded presentation with audio, final white paper, prepared audience Q&A, and code |
